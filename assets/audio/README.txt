PANDUAN MUSIK LATAR (AUDIO):
====================================
1. Masukkan file lagu romantis instrumental favorit Riki (format .mp3) ke dalam folder ini.
2. Beri nama file: "bgm.mp3" (sehingga lokasinya menjadi: assets/audio/bgm.mp3).
3. Website sudah otomatis dikonfigurasi untuk membaca "assets/audio/bgm.mp3".
4. Jika file belum dimasukkan, website memiliki fallback audio synthesizer melodi piano lembut sehingga tetap mengeluarkan alunan musik romantis saat tombol pembuka ditekan!
